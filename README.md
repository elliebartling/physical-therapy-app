# PT App

iOS app for following a PT-prescribed routine. See `docs/superpowers/specs/2026-06-14-pt-app-design.md`.

## Build

Open `App/PTApp.xcodeproj` in Xcode 16+ (Swift 6 toolchain). Build the `PTApp` scheme to a device or simulator running iOS 26+.

## Test

`Cmd-U` in Xcode runs all XCTest targets across the `PTAppCore` package.
